## 6.2 Integration Testing

**Scope:** Verifies the interaction between the React frontend, FastAPI backend, authentication module, RBAC authorization, endpoint posture records, alert management, traffic monitoring APIs, and protected resource access gate.

**Tool:** Automated Playwright browser tests running against the real FastAPI backend and SQLite database (default `zt_suite.db`). Tests simulate real user interactions through the browser.
